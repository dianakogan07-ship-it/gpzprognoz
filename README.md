# Прогноз цен ГПЗ

Веб-сервис: по ГПЗ и Отчётности базового года строит обезличенный справочник прогнозных цен за единицу (без НДС) на следующий год.

Файлы ГПЗ и Отчётности читаются в браузере и на сервер не передаются. Сервер хранит только справочники и индексы.

## Логика расчёта

1. Строки ГПЗ связываются с Отчётностью по реестровому номеру лота (запасной вариант — ID процедуры). Не заключённые договоры, строки без цены, ОКПД2, количества или ед. изм. попадают на лист «Не вошли».
2. Цена за единицу = фактическая цена договора без НДС / количество (если в отчётности только цена с НДС — пересчёт по ставке).
3. Доведение до уровня декабря базового года — индекс `to_december` (ИЦП Росстата) по ОКПД2 и месяцу заключения.
4. Группа = ОКПД2 + ед. изм. + регион + код WS. Медиана; значения, отличающиеся от медианы более чем в 2 раза, исключаются. Менее 3 договоров — «малая выборка».
5. Прогноз = медиана × индекс `forecast` (дефлятор МЭР): по самому длинному префиксу ОКПД2, затем по разделу ОКВЭД2. Если не найден — прогноз ИПЦ (`cpi`) и пометка «требует согласования». Неутверждённый индекс — тоже «требует согласования».
6. Повторяемость — по справочнику правил (код WS, затем префикс ОКПД2). Разовые — «ориентир справочный».
7. Новые коды WS из отчётности автоматически добавляются в справочник.

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # проверки расчёта
```

Без `DATABASE_URL` сервис работает на встроенных справочниках в режиме только чтения.

## Развёртывание на Vercel (бесплатно)

1. Импортировать репозиторий в Vercel (New Project → GitHub → `gpzprognoz`), фреймворк Next.js определится сам.
2. Storage → Create Database → Neon (Postgres, бесплатный план) → подключить к проекту. Переменная `DATABASE_URL` появится автоматически.
3. Settings → Environment Variables: `BASIC_AUTH_USER`, `BASIC_AUTH_PASSWORD` — логин и пароль для экрана входа (сессия хранится 30 дней).
4. Создать таблицы и стартовые справочники (один раз, с локального компьютера):
   ```bash
   DATABASE_URL="строка подключения из Vercel" npm run db:setup
   ```
5. Redeploy. Затем на странице «Индексы роста» скачать шаблон, заполнить ИЦП и дефляторы и загрузить обратно.

Прогноз ИПЦ на 2027 г. (4%, МЭР, сентябрь 2026) внесён как неутверждённый — проверьте и отметьте «Утверждён».

## Загрузка прогноза МЭР

Раздел «Индексы роста» → «Загрузить прогноз МЭР» принимает PDF или XLSX прогноза социально-экономического развития как есть. Сервис находит таблицу «Прогноз индексов цен производителей и индексов-дефляторов по видам экономической деятельности» (базовый вариант) и ИПЦ, показывает предпросмотр и сохраняет значения со статусом «Нужна проверка». Утверждённые индексы не затираются: изменившееся значение сохраняется новой версией, которая заменит прежнюю после утверждения. PDF больше 4 МБ разбирается в браузере, на сервер уходит только текст нужных страниц. Ссылки «Где взять данные» — в `lib/sources.ts`. Тестовый PDF: `python3 scripts/make-mer-fixture.py tests/fixtures/mer-sample.pdf`.
