# Правила работы в проекте

- Изменения сразу пушить в `main` (прод на Vercel), без PR. При проблемах — откат коммита.
- Пушить только в `main`: если тот же коммит одновременно уходит в другие ветки, Vercel собирает превью, а прод может не обновиться.
- Перед пушем: `npm test`, `npx tsc --noEmit`, `npx next build`.
- Интерфейс — на русском, для закупщика без технической подготовки; стиль как в остальных разделах (кнопки `.btn`/`.btn-sec`, карточки `.card`).
